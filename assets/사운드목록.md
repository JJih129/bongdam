## 적용 시 참고 (미적용 상태)

- BGM: `봉담지킴이_게시용_v320_final.html`의 `window.BD_BGM_SLOTS`(약 25427행)에 경로 연결.
  확장자 주의: title/house/ending = mp3, field/tension/battle/boss = ogg.
  현재 게임 코드는 battle/boss(전투 진입)와 field(전투 종료)만 자동 재생 훅이 있음 —
  title/house/tension/ending은 적용 시 장면 전환 훅 추가 필요.
- 효과음: `BDSound`(약 19184행)의 각 함수를 파일 재생으로 교체하되, 로드 실패 시 기존 Web Audio 합성음 폴백 유지 권장.
- 배포 시 HTML과 `assets\` 폴더(`_원본팩` 제외 가능)를 함께 전달.
